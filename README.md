# 💕 DatingApp

**Une application de dating moderne et élégante**

[🌐 Voir l'application](https://dating-app-black.vercel.app) · [📖 API Swagger](https://dating-app-api-50zf.onrender.com/swagger)

</div>

***

## ✨ Fonctionnalités

| | Fonctionnalité | Description |
|---|---|---|
| 🔐 | **Authentification** | Inscription / Connexion sécurisée avec JWT + Refresh Token |
| 👤 | **Profil utilisateur** | Photo de profil, bio, ville, pays |
| 📸 | **Gestion des photos** | Upload, suppression, définir une photo principale (max 6) |
| 🎯 | **Préférences** | Genre souhaité, tranche d'âge, distance maximale |
| 💘 | **Swipe** | Like ❤️ · Nope ✖️ · Super Like ⭐ |
| 🤝 | **Matching** | Détection automatique des matchs mutuels |
| 💬 | **Chat temps réel** | Messagerie instantanée via WebSockets |
| 🔔 | **Notifications** | Nouveau match, nouveau message en temps réel |
| 🌙 | **Dark Mode** | Thème clair et sombre |
| 📱 | **Mobile-first** | Design responsive optimisé mobile |

***

## 🧱 Technologies utilisées

### 🎨 Frontend
| Technologie | Rôle |
|---|---|
| [Next.js 15](https://nextjs.org) | Framework React (App Router) |
| [TypeScript](https://typescriptlang.org) | Typage statique |
| [Tailwind CSS](https://tailwindcss.com) | Styling utilitaire |
| [SignalR JS](https://learn.microsoft.com/aspnet/signalr) | Chat temps réel |

### ⚙️ Backend
| Technologie | Rôle |
|---|---|
| [ASP.NET Core (.NET 10)](https://dotnet.microsoft.com) | API REST |
| [Entity Framework Core](https://learn.microsoft.com/ef/core) | ORM Code First |
| [MediatR](https://github.com/jbogard/MediatR) | Pattern CQRS |
| [FluentValidation](https://fluentvalidation.net) | Validation des entrées |
| [SignalR](https://learn.microsoft.com/aspnet/signalr) | WebSockets temps réel |
| [Serilog](https://serilog.net) | Logging structuré |
| [BCrypt](https://github.com/BcryptNet/bcrypt.net) | Hash des mots de passe |
| [JWT Bearer](https://jwt.io) | Authentification par token |

### 🗄️ Infrastructure
| Technologie | Rôle |
|---|---|
| [PostgreSQL](https://postgresql.org) | Base de données principale |
| [Redis](https://redis.io) | Cache et sessions |
| [Cloudinary](https://cloudinary.com) | Stockage des photos |
| [Vercel](https://vercel.com) | Hébergement frontend |
| [Render](https://render.com) | Hébergement backend + BDD |
